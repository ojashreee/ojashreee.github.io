About me

I build things
to understand them.

I learn best by building. I like taking something I don't fully understand, breaking it down, experimenting with it, and gradually turning it into something that works.

I'm an aspiring Software Engineer with a growing interest in full-stack development — building interfaces with React and JavaScript, and working with Java, Python, SQL, APIs, and databases. I'm especially curious about what happens behind the interface and how the parts of a system fit together.

Most of my learning happens through projects involving API integration, authentication, state management, and databases. Each one has taught me how to debug, think through a problem, and build in a structured way.

I'd rather ask “why does this work?” than just “how do I make this work?” Good engineering, to me, is learning, building, breaking, fixing, and improving. I'm still early in my journey, but I'm excited about the process — one project at a time.
